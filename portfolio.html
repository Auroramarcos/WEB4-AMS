Componente Reutilizable: Card de Proyecto

Este componente de card reutiliza el patrón de diseño de Bootstrap. Se puede aplicar para mostrar distintos tipos de contenido (proyectos, productos, artículos, etc.) cambiando solo el texto y la imagen.

Versión 1 – Proyecto

Usando la misma estructura de card para mostrar un proyecto con descripción breve.

Versión 2 – Producto

La misma card usada para un producto, simplemente cambiando la información.

Versión 3 – Artículo

Otra variación de la misma card para un artículo de blog.
